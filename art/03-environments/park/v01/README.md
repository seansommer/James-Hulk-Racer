# Emerald Park environment kit

Five independent original assets: `backdrop`, `canopy`, `tree`, `shrub`, and `gateway`. The backdrop is opaque; the other four preserve transparency, including the gateway opening and gaps between tree branches. `sources` preserves originals, while `textures-512` and `textures-1024` contain runtime/review exports.

The shared [library manifest](../../../02-items/park/v02/library.json) records sizes, alpha statistics, source hashes and pivots. The [art and motion notes](../../../02-items/park/v02/README.md) cover candidate status and next work.

Tree animation candidates are archived with the shared Emerald motion package. Shrub movement in the current preview is a small runtime sway; canopy, gateway and backdrop have no generated animation frames yet. The backdrop is one flattened distant scene; its waterfall is not falsely described as a separated animated layer.

Track curvature is real game geometry. These illustrations supply scenery around that half-pipe, not a painted substitute for the playable surface.
