## Source preservation and export contract

- Original images retain their generated bytes. Sources are typically 1254 × 1254 for objects; actual dimensions and SHA-256 hashes are recorded in `library.json`.
- `textures-512` and `textures-1024` are ordinary reduced exports, preserving true alpha. High-resolution sources are retained separately.
- `motion/sources` contains original animation sheets, including rejected tree attempts for traceability.
- `motion/frames-512` contains registered frame canvases. These are export dimensions, not a claim of 512 pixels of original detail in every sheet cell.
- `motion/atlases` contains runtime sheets with four-pixel gutters. Object cells are 256 × 256; tree cells are 512 × 512.
- Registration uses translations and **one shared scale per clip**. Source rectangles, source anchors, crop rectangles, common scale, output pivots, timing, frame order, and hashes are stored in `library.json`. Each frame is not independently stretched to fill a box.
- Generated RGB visible in fully transparent pixels must not be mistaken for a rendered glow. Alpha was checked by compositing against both light and dark backgrounds.
- Pivots describe presentation. Existing game rules remain authoritative for collection and collision footprints; debris never silently changes those rules.

Rebuild from the art checkout with `node scripts/build-emerald-library.mjs` after installing the repository's dependencies. Native image generation prompts and source file provenance are in `art/emerald-generation-session.json` and `art/emerald-animation-session.json`.

## Motion review findings

The first tree animation sheet clips some foliage. The lower row of the second tree sheet changes branch identity. The runtime keeps only the second sheet's top three poses and plays them forward/backward. More wind in-betweens and steadier roots remain necessary for final quality. No claim is made that the six generated poses were all accepted.

Gem and star turning need closer loop and angular-speed review. Star motion has only six angles and can look stepped at large sizes. Bumper shell stability and goo highlight continuity also need polish. Rock destruction is deliberately a triggered reaction; intact rocks do not crumble repeatedly while waiting on the track.
